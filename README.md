# React Password Manager

This project uses React as its backend and was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Available Scripts

To start the application, you can run:

### `npm start`

The shown command runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm run build`

This command creates a build folder inside the project that can be used for production purposes.
To start the server in a build folder, you need to first install `serve` via npm: `npm install -g serve`
After `serve` is installed, you can execute the following command: `serve -s [DIRECTORY]` ([DIRECTORY] is the path to the build folder)
